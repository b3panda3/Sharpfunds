# Sharpfunds

**AI-Powered Multi-Asset Financial Intelligence Platform**

Built primarily with [native.builder](https://native.builder) for the AI Factory / Native.builder Hackathon (Aug 3–10, 2026).

---

## Problem Being Solved

Retail investors, financial enthusiasts, and students face a fragmented landscape when tracking financial markets. Stock data lives on one platform, crypto on another, forex on yet another — and AI-powered analysis tools are either prohibitively expensive or locked behind institutional paywalls. There is no single, free, unified dashboard that aggregates data across stocks, S&P 500 ETFs, major cryptocurrencies, meme tokens, commodities, and forex pairs while providing contextual AI insights grounded in real-time market data.

**Sharpfunds solves this** by aggregating 6 asset classes into a single intelligent dashboard with live market data, contextual AI commentary, news analysis, and personalized onboarding — all powered by free APIs and open-source models.

---

## Target User

- **Primary**: Individual retail investors (ages 22–45) who track multiple asset classes and want a unified view
- **Secondary**: Finance students and enthusiasts who want AI-powered explanations of market movements
- **Tertiary**: Day traders and meme-coin watchers who need quick multi-market snapshots

---

## Key Features

- **Multi-Asset Dashboard** — Real-time data for stocks, crypto, meme coins, forex, S&P 500 ETFs, and commodities with floating AI placards
- **Asset Insights** — Detailed per-asset pages with interactive price charts, key stats, fundamentals, and AI-generated synthesis
- **AI-Powered Chat** — Global AI assistant (Groq + Gemini) and per-asset chat with contextual market awareness
- **News Feed** — Classified financial news with AI-powered news analysis chatbot
- **Smart Watchlist** — Persistent watchlist (localStorage + Supabase) with grouped views by asset class
- **Personalized Onboarding** — 4-step wizard capturing risk tolerance, experience level, and preferred asset classes
- **Google OAuth** — Seamless sign-in via Google through Supabase Auth
- **Responsive Design** — Full mobile/tablet/desktop support with adaptive layout

## How native.builder Was Used

native.builder was the primary tool used to generate the Sharpfunds application. The development process involved:

1. **Iterative Prompt Engineering**: Eight sequential prompts were crafted and submitted to native.builder, each targeting a specific feature module:
   - Project shell with Supabase auth scaffolding and routing architecture
   - Dashboard page with stat cards, floating placards, and top movers table
   - Stock/asset detail page with charts, fundamentals, and AI synthesis
   - Crypto and meme coin pages with real-time pricing
   - Forex pair tracking with multi-currency support
   - News feed with classification and AI chatbot
   - AI chat integration with global assistant and per-asset chat
   - Profile, settings, and onboarding flow

2. **Architecture Generated by native.builder**: The tool produced the complete React + TypeScript project structure including:
   - Vite build configuration with Tailwind CSS v4, SVGR plugin, and health check endpoint
   - React Router v7 SPA routing with auth guards and onboarding flow
   - Supabase client integration with auth context and user profile management
   - Component hierarchy: layout (Sidebar, Header, AppLayout, MobileNav, GlobalAIAssistant), pages (Dashboard, AssetInsights, News, Watchlist, Settings, Onboarding, Health, Privacy, Disclaimer), and domain components (NewsAIChatbot)
   - Custom CSS design system with glassmorphism, glow animations, and dark-mode-first theming via Tailwind v4 `@theme` tokens
   - Type-safe interfaces for all data models (UserProfile, WatchlistItem, MarketMover, NewsArticle, ChatMessage, etc.)

3. **Post-Generation Enhancement**: After native.builder generated the initial codebase, the following improvements were made:
   - Replaced all mock/hardcoded data with real API integrations (Finnhub, CoinGecko, Alpha Vantage, Frankfurter, NewsAPI)
   - Wired AI functions to Groq and Gemini instead of pattern-matched hardcoded responses
   - Added Supabase edge function for server-side AI chat (`global-ai-chat`)
   - Implemented watchlist persistence to Supabase database
   - Fixed Vercel SPA routing with `vercel.json` rewrites
   - Removed hardcoded credentials, added proper environment variable management
   - Created the `watchlist_items` Supabase table schema for cross-device sync

## Architecture

```
sharpfunds.vercel.app (Vite SPA)
├── src/
│   ├── pages/          (Dashboard, AssetInsights, News, Watchlist, etc.)
│   ├── components/     (Layout: Sidebar, Header, MobileNav, GlobalAIAssistant)
│   ├── contexts/       (AuthContext, WatchlistContext)
│   ├── lib/            (api.ts, supabase.ts, newsClassifier.ts, constants.ts)
│   └── types/          (TypeScript interfaces)
├── supabase/functions/
│   ├── global-ai-chat/ (Edge function: Groq/Gemini AI chat)
│   └── market-data-proxy/ (Edge function: unified data proxy)
└── vercel.json         (SPA rewrite rules)

Data Flow:
Frontend → api.ts → [Finnhub, CoinGecko, Alpha Vantage, Frankfurter, NewsAPI] → Fallback cache
Frontend → GlobalAIAssistant → [Supabase Edge Function (Groq/Gemini)] → [Client-side Groq/Gemini fallback]
Frontend → AuthContext → Supabase Auth (Google OAuth / email)
Frontend → WatchlistContext → localStorage + Supabase (watchlist_items table)
```

## Supabase Setup

### Tables

```sql
-- User profiles (extends Supabase auth.users)
CREATE TABLE IF NOT EXISTS user_profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  email TEXT,
  display_name TEXT,
  avatar_url TEXT,
  asset_classes TEXT[] DEFAULT '{}',
  risk_tolerance TEXT DEFAULT 'balanced',
  experience_level TEXT DEFAULT 'intermediate',
  onboarding_complete BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Watchlist items (per-user, cross-device sync)
CREATE TABLE IF NOT EXISTS watchlist_items (
  id TEXT PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
  symbol TEXT NOT NULL,
  name TEXT NOT NULL,
  asset_class TEXT NOT NULL,
  added_at TIMESTAMPTZ DEFAULT NOW()
);
```

### RLS Policies

```sql
-- user_profiles
ALTER TABLE user_profiles ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can view own profile" ON user_profiles FOR SELECT USING (auth.uid() = id);
CREATE POLICY "Users can update own profile" ON user_profiles FOR UPDATE USING (auth.uid() = id);
CREATE POLICY "Users can insert own profile" ON user_profiles FOR INSERT WITH CHECK (auth.uid() = id);

-- watchlist_items
ALTER TABLE watchlist_items ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can view own watchlist" ON watchlist_items FOR SELECT USING (auth.uid() = user_id);
CREATE POLICY "Users can insert own watchlist" ON watchlist_items FOR INSERT WITH CHECK (auth.uid() = user_id);
CREATE POLICY "Users can delete own watchlist" ON watchlist_items FOR DELETE USING (auth.uid() = user_id);
CREATE POLICY "Users can update own watchlist" ON watchlist_items FOR UPDATE USING (auth.uid() = user_id);
```

### Google OAuth Setup

1. Go to [Google Cloud Console](https://console.cloud.google.com/) → APIs & Services → Credentials
2. Create an OAuth 2.0 Client ID (Web application)
3. Add authorized redirect URI: `https://<your-project-ref>.supabase.co/auth/v1/callback`
4. Copy Client ID and Client Secret
5. In Supabase Dashboard → Authentication → Providers → Google:
   - Enable Google provider
   - Paste Client ID and Client Secret
   - Add your app URL to "Redirect URLs": `https://sharpfunds.vercel.app`

### Edge Function Secrets

In Supabase Dashboard → Edge Functions → Settings:

- `GEMINI_API_KEY`
- `FINNHUB_API_KEY`
- `ALPHA_VANTAGE_API_KEY`
- `COINGECKO_API_KEY`
